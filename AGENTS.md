# IndieLens — Project Instructions

## Project
IndieLens is a personalized indie-game recommendation system.

## Goals
- Learn ML engineering through hands-on implementation.
- Build recommendation models using Python and PyTorch.
- Evaluate using metrics such as Recall@K and NDCG@K.
- Eventually deploy an API using FastAPI, Docker, and GCP.

## How to assist me
- I am learning ML engineering.
- Explain unfamiliar Python syntax and engineering concepts.
- Do not implement entire features without explaining the approach first.
- Prefer small, understandable changes.
- Explain mathematical concepts behind ML algorithms.
- When suggesting changes, explain why they are necessary.
- Help me understand errors rather than merely fixing them.
- Run relevant tests after code changes when possible.
